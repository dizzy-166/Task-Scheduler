# ControlFlow — Frontend

React + Vite фронтенд для [ControlFlow](../../README.md).

## Запуск

```bash
npm install
npm run dev
```

## Переменные окружения

Создай `.env.local`:

```
VITE_API_URL=http://localhost:8000/api/v1
VITE_CEREBRAS_API_KEY=твой_ключ_с_cloud.cerebras.ai
```

## Сборка

```bash
npm run build
```
